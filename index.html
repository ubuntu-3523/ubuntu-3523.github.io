✦ GITHUB PAGES

나만의 사이트 만들기

GitHub Pages로 무료로 자신만의 URL에 사이트를 올릴 수 있어요.

🐙 GitHub Pages 시작하기
가입부터 배포까지 5단계, 완전 무료!
1
github.com 가입 → 새 저장소 만들기
이름은 아이디.github.io 형식으로!
2
이 index.html과 교육자료 HTML 파일들을 저장소에 업로드
3
Settings → Pages → Source를 main 브랜치로 설정
4
몇 분 뒤 https://아이디.github.io 로 접속하면 완성!
5
링크를 학생·학부모에게 공유 — 스마트폰에서 바로 접속 🎉
